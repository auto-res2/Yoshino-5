# Predictive Task Scheduling: Online Curriculum Planning to Reduce Forgetting in PEFT-based Continual Learning
> ⚠️ **NOTE:** This research is an automatic research using AIRAS.
## Abstract
We study task-order selection in continual learning with parameter-efficient fine-tuning (PEFT), where large backbones are adapted via small trainable modules and re-ordering tasks post hoc is infeasible. Poor ordering exacerbates catastrophic forgetting and widens stability gaps, yet most pipelines rely on random or chronological orderings or static similarity heuristics that do not scale or adapt online [lange-2022-continual]. We propose Predictive Task Scheduling (PTS), an online curriculum engine that selects the next task from a small look-ahead buffer using ultra-cheap, frozen-backbone surrogates and a meta-learned scorer. For each candidate we compute, on at most 32 samples, feature affinity via centred-kernel-alignment, PEFT-only gradient conflict using a PCGrad-style cosine [yu-2020-gradient], and a linear-mode connectivity loss along a one-step interpolation [mirzadeh-2020-linear]. A tiny MLP predicts long-term accuracy drop, and a beam search composes scores at O(K^2) cost. PTS is adapter-agnostic (LoRA, spectral adapters, SURM) [zhang-2024-spectral, sehanobish-2024-structured] and uses a small replay-anchor buffer. In a sanity run with three tasks, PTS improves final mean accuracy by 1.49–2.36 percentage points over chronological and random orders and achieves the most negative average forgetting, indicating reduced interference with negligible overhead. We release a reference implementation and a protocol for larger-scale evaluation, ablations, and robustness analyses.
