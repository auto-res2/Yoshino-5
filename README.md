# Dynamic Curriculum Ordering with Dual Signals for Continual Learning
> ⚠️ **NOTE:** This research is an automatic research using AIRAS.
## Abstract
Catastrophic forgetting in continual learning is notoriously sensitive to task order, especially for large transformers where an unlucky permutation can waste days of compute. We address the open problem of online task ordering with DyCLOS, a model-agnostic curriculum that schedules tasks on the fly using two lightweight signals computed from a small probe per task. The first is data similarity measured via an optimal-transport dataset distance in a shared frozen embedding space, and the second is gradient interference estimated as the cosine of adapter gradients. DyCLOS constructs a dynamic curriculum graph with edge costs that combine dissimilarity and interference, then maintains a minimum-cost Hamiltonian path prefix by solving a sliding-window beam search as tasks arrive. Training updates are limited to parameter-efficient APD-style adapters, and a stability-aware inner loop attenuates transient performance drops. We implement a reproducibility toolkit and evaluate DyCLOS in three settings: a synthetic-vision sanity check, a compact CIFAR class-incremental stream, and a synthetic NLP multi-task stream. Across these, DyCLOS improves final accuracy by 0.9–3.3 percentage points over fixed or random orders and reduces average forgetting by 33–88%, with small absolute overhead; ablations verify that combining both signals yields the best stability–plasticity trade-off. These findings show task ordering is a controllable lever and that DyCLOS offers a practical, modality-agnostic curriculum layer for continual training pipelines.
