# Hierarchical Graph Dual-Path Transformer with Adaptive Tokenization

## Abstract
We present a novel Hierarchical Graph Dual-Path Transformer with Adaptive Tokenization (HGDP-AT) that addresses the trade-off between capturing fine-grained local interactions and modeling long-range dependencies in graph neural networks. In many applications such as bioinformatics and social network analysis, models focusing solely on local details risk missing global structure, while methods that aggregate global information often sacrifice interpretability and computational efficiency. Our approach mitigates these issues by dynamically generating tokens from substructures via a learnable attention mechanism and by processing graph data along two complementary streams that preserve both detailed node-level information and tokenized global summaries. The key contributions include: a dynamic tokenization module that automatically selects informative nodes, a dual-path transformer architecture that fuses local embeddings with global context using iterative cross-attention, and a hierarchical message passing framework with dynamic routing that adaptively aggregates features while preserving interpretability. We evaluate HGDP-AT on benchmark datasets from TUDataset (PROTEINS and IMDB-BINARY) and OGB (ogbg-molhiv) using PyTorch and PyTorch-Geometric. Experimental results indicate competitive performance with a preliminary test accuracy of approximately 65.5% on the PROTEINS dataset. In addition, visualizations of dynamic token attention provide empirical evidence supporting improved interpretability. These findings demonstrate that the proposed framework not only achieves competitive accuracy but also offers a transparent mapping from local substructures to global representations, creating promising avenues for future work in heterogeneous graphs and multi-task settings.
