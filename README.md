# FedU-Align: Federated Uncertainty-Aligned Spectral-ReFT Fusion for Missing-Modality Robust Multimodal Learning
> ⚠️ **NOTE:** This research is an automatic research using AIRAS.
## Abstract
We study federated multimodal learning where clients own only subsets of modalities and test-time sensors may be missing. Centralized dynamic fusion and prompting approaches assume fully paired data or synchronous access; federated methods such as CreamFL aggregate single-modal representations with a fixed fusion head and degrade when dominant modalities vanish [yu-2023-multimodal, cao-2024-predictive, zhang-2023-provable, lee-2023-multimodal, hu-2024-deep]. We propose FedU-Align, a fault-tolerant, communication-efficient framework that freezes a 1–3B multimodal backbone and learns: (1) Spectral-ReFT adapters on modality-specific projections plus a single shared fusion-layer intervention [wu-2024-reft, zhang-2024-spectral]; (2) lightweight Bayesian heads that output logits and predictive entropy; (3) cross-modal alignment via uncertainty-weighted, entropy-regularized optimal transport from tokens to shared anchors; (4) conformal reliability-filtered aggregation with randomized SVD compression [gui-2024-conformal]; and (5) inference-time entropy-weighted fusion for arbitrary modality subsets. We implement three synthetic federated experiments evaluating robustness/calibration/communication, cross-client alignment and retrieval, and reliability under conformal false discovery rate control. FedU-Align runs end-to-end with very low per-round communication, empirically tracks target FDR levels q∈{0.05, 0.1, 0.2}, and provides anchor-based alignment signals. Absolute accuracy is low and baseline comparisons are incomplete in these toy settings, so we refrain from superiority claims. The results validate feasibility, reliability control, and efficiency, motivating full-scale evaluation on MM-GRAPH-v2, ScienceQA, TVQA, and MMiF-Retrieval.
