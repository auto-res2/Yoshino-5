# Physically-Aware Hierarchical GaLore for Memory-Efficient SciML Training
> ⚠️ **NOTE:** This research is an automatic research using AIRAS.
## Abstract
Training billion-parameter scientific machine learning (SciML) models on commodity GPUs is impeded by optimizer-state memory and by the need to preserve physical constraints. Gradient low-rank projection, exemplified by GaLore, reduces optimizer memory by projecting gradients into low-dimensional subspaces while keeping all weights trainable, but suffers from costly full-matrix SVD refreshes, physics-agnostic subspaces, and limited evaluation beyond NLP [zhao-2024-galore]. We introduce Physically-Aware Hierarchical GaLore (Phi-GaLore), a two-stage gradient projection framework for SciML. Stage 1 maintains an exponential-moving-average randomized sketch of each large gradient using CountSketch on rows and columns to form a tiny r×r core in O((m+n)r) time per step. Stage 2 periodically performs an SVD on the r×r covariance of this core and augments the resulting learned subspace with analytic physics bases (e.g., divergence-free and SO(3)-aligned blocks), followed by orthonormalization and cross-layer projector sharing. This design eliminates large SVDs, encodes domain symmetries, and amortizes cost across layers, and is implemented as a drop-in PyTorch optimizer wrapper compatible with 8-bit states and FLORA-style compression [hao-2024-flora]. In instrumented, short-horizon PyTorch studies, Phi-GaLore achieves near-perfect cosine alignment with full gradients at rank 32, reduces divergence norms on a toy incompressible Navier–Stokes task when injecting a divergence-free basis, and lowers per-step overhead via hierarchical sharing. While these brief runs do not demonstrate steady-state wall-clock gains over GaLore or quantify memory savings at scale, the observed behaviors validate the core mechanisms and motivate longer SciML evaluations on PINNsFormer, Transolver, and molecular transformers [zhao-2023-pinnsformer, wu-2024-transolver, chen-2024-geomformer, alkin-2024-universal, bryutkin-2024-hamlet].
