# BACS: Budget-Aware Control of Self-Reasoning in Compact Language Models
> ⚠️ **NOTE:** This research is an automatic research using AIRAS.
## Abstract
We study test-time compute scaling for compact (≤7B) language models under strict FLOP and latency budgets. Static chain-of-thought depths and fixed tool cascades are mismatched to instance difficulty, while process reward models (PRMs) can grade intermediate steps but do not decide when to continue reasoning, which tools to invoke, or when to stop. We propose BACS, a Budget-Aware Controller for Self-Reasoning: a tiny policy network trained with reinforcement learning to maximize an expected utility Acc − λ·Compute, conditioned on the evolving reasoning trace, PRM scores, and calibrated per-action costs. BACS chooses among actions {advance, branch, call calculator/python/retrieval/verifier, skip-to-final, terminate}, and is distilled into a 1–2B meta-reward model for fast deployment. We implement a reproducible evaluation suite spanning cost calibration, a PRM, four specialist adapters, and baselines (beam-5 rerank, fixed cascades). On a synthetic arithmetic-and-trap set we report an initial negative result: the distilled controller under-utilizes the calculator and is dominated by a deterministic cascade, though action-agreement with the teacher reaches 0.862. Causal ablations confirm the failure mode and suggest remedies. Despite the setback, the framework unifies PRM feedback and compute-aware scheduling and provides a modular path toward adaptive reasoning on edge-sized models.
