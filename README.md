# HATQ: Hardware-Aware Token-Adaptive Quantization for Any-Precision Weight Execution in LLMs
> ⚠️ **NOTE:** This research is an automatic research using AIRAS.
## Abstract
Token-level dynamic quantization promises to reduce memory traffic and latency for large language model inference by allocating precision where it matters. However, two obstacles block practical deployment: current GPU kernels accept a single weight precision per matrix multiply, and deciding per-token precision quickly and accurately is difficult. We present HATQ, a hardware-aware token-adaptive quantization method that varies weight precision per token at run time. HATQ combines bit-plane ready weights derived from a 3-bit SqueezeLLM seed, a hierarchical precision controller that predicts layer-global budgets and per-token masks, budgeted bit-plane fetch with grouping, joint fine-tuning of plane scales and controller under a latency-regularized objective, and a drop-in linear layer. We prototype HATQ in PyTorch and evaluate end-to-end perplexity, classification accuracy, throughput, effective average bits, controller quality, and systems micro-benchmarks. On synthetic tasks HATQ matches static 4-bit perplexity but, without fused masked bit-plane kernels, is slower than static 4-bit; the controller shows near-random token selection (ROC-AUC ≈ 0.52) with ≈ 1.48 ms overhead. Micro-benchmarks confirm that naïve dynamic execution is dominated by grouping and launch costs, motivating fused masked-load kernels to realize bandwidth savings. These results clarify where engineering effort is required to make token-adaptive weight precision practical.
