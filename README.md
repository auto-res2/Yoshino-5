# Adaptive Basis LoRA: Temporal-Complexity-Scaled PEFT for Video-LLMs
> ⚠️ **NOTE:** This research is an automatic research using AIRAS.
## Abstract
We address a central bottleneck in video–language models: temporal reasoning under strict token and parameter budgets. Existing parameter-efficient fine-tuning (PEFT) methods such as LoRA and DoRA enforce a fixed small rank across time, compressing complex motion into a handful of shared directions and encouraging aggressive frame dropping, which harms temporal consistency and boundary localization [hu-2021-lora, liu-2024-dora]. We propose Adaptive Basis LoRA (AB-LoRA), a plug-and-play adapter that replaces the single static low-rank update with a video-adaptive mixture of bases. For each video, we estimate a variable number of orthogonal temporal bases in CLIP latent space using EM with MDL/BIC selection and train a lightweight temporal encoder to predict per-time-step responsibilities [li-2023-video]. Each attention block mixes basis-specific directions and magnitudes in a DoRA-style decomposition, with Householder-inspired compression for parameter reduction [liu-2024-dora, dong-2024-efficient]. Training proceeds in three stages: feature alignment, basis pretraining with an MDL-GMM teacher on WebVid-scale data [bain-2021-frozen], and instruction tuning with the basis encoder frozen. We provide a full experimental plan covering datasets, metrics, fairness controls, robustness grids, and ablations, plus PyTorch skeletons. A minimal synthetic sanity check verifies end-to-end feasibility; it is not a benchmark evaluation. AB-LoRA establishes a principled route to temporally adaptive PEFT that can be layered on existing Image-LLMs to enable consistent long-video understanding.
