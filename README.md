# Magnitude-Guided Adaptive Masked Attention for Quantized PEFT Models
> ⚠️ **NOTE:** This research is an automatic research using AIRAS.
## Abstract
Sparse attention, parameter-efficient fine-tuning, and 4-bit quantization each improve the efficiency of small language models, yet jointly they often degrade exact multi-step mathematical reasoning despite near-identical perplexity. We address this with MAGMA, a magnitude-guided adaptive masked attention mechanism that learns block-sparse attention patterns during DoRA fine-tuning and reuses them at inference with zero per-sample overhead. MAGMA repurposes DoRA’s learned per-row magnitude channel as a stable token-importance signal, combines it with Q/K activation norms into per-block scores, aggregates these via an exponential moving average, and solves a global budgeted selection to produce GPU-friendly masks that enable K/V compaction in Flash-style kernels. Unlike runtime-estimated or RL-based sparsity, MAGMA learns once, is fully compatible with 4-bit NF4 adaptation, and preserves training stability by decoupling mask statistics from main gradients. We release a PyTorch-first reference and evaluate three axes: efficacy under high sparsity, long-context robustness via mask tiling, and token-importance faithfulness. In our small-scale reference runs (≈60 steps, synthetic data, no optimized kernels), all models reach 0% exact match; however, MAGMA’s keep probabilities correlate with math-token density (Spearman 0.51), supporting the core design. We discuss limitations and a roadmap toward conclusive evaluation on 7B backbones with Flash-compatible sparse kernels and standardized math benchmarks [liu-2024-dora, dettmers-2023-qlora, dettmers-2022-the, pagliardini-2023-fast, tay-2020-long].
