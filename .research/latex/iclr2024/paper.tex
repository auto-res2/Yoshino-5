\begin{abstract}
We propose a novel method to augment the MambaFormer architecture with an adaptive computation scheduling mechanism that dynamically allocates computation routes at token and layer levels. By integrating a lightweight decision module that evaluates token-level features, our approach selectively routes tokens through full self-attention, efficient linear state-space computations, or sparse attention branches. This dynamic branch selection addresses inefficiencies inherent in static hybrid modules, particularly on devices with constrained resources or in real-time applications. Our method builds on differentiable gating strategies and dynamic sparsification techniques to minimize redundant computations and memory consumption. We validate our approach through extensive experiments that compare inference speed, memory usage, and accuracy on standard NLP tasks—such as text classification with IMDB and translation tasks evaluated via BLEU scores—as well as on synthetic datasets with controlled token complexity. Although the current implementation shows increased inference time due to decision overhead, our results demonstrate the feasibility of adaptive processing and highlight potential gains that can be achieved through refined gating and threshold tuning, opening promising avenues for hardware-aware, adaptive sequence modeling \cite{gu\_2021-10-26T19:44:53Z\_combining, huang\_2024-05-31T10:41:03Z\_decision}.
\end{abstract}

\section{Introduction}
\label{sec:intro}
The rapid evolution of deep neural architectures has spurred significant interest in hybrid models that combine diverse computational strategies to efficiently process long-range dependencies. Models such as MambaFormer, which integrate linear state-space computations with self-attention, have shown promise in reducing the quadratic cost of traditional attention mechanisms \cite{gu\_2021-10-26T19:44:53Z\_combining}. However, these architectures typically follow a fixed ordering of modules regardless of input complexity, leading to unnecessary computational expenditure on simpler inputs. In real-world applications, particularly those requiring real-time processing or deployment on resource-constrained devices, such inefficiencies can be critical. To address this gap, we introduce an adaptive computation scheduling mechanism within the MambaFormer framework. Our model employs a lightweight dynamic scheduler that evaluates token-level features—such as the mean activation of each token—through a compact feed-forward network. This gating mechanism produces a decision metric that determines whether a token should be processed via full self-attention or be rerouted to a more efficient branch, such as sparse attention or linear state-space computation.

\begin{itemize}
  \item \textbf{Dynamic Scheduler:} The design and integration of a dynamic scheduler using a differentiable gating module for selective branch activation.
  \item \textbf{Dynamic Sparsification:} The implementation of dynamic sparsification methods to reduce redundant computations when processing low-complexity inputs.
  \item \textbf{Experimental Evaluation:} A comprehensive experimental evaluation comparing the adaptive model with a static hybrid baseline, focusing on inference speed, memory utilization, and task accuracy.
\end{itemize}

In our experiments, we benchmark both models on standard NLP tasks and synthetic datasets with controlled token difficulties. While the decision overhead currently results in increased inference time compared to static approaches, our framework provides a flexible basis for further refinement. Future work will focus on alternative gating strategies and reinforcement learning approaches to better balance resource allocation. This research builds upon and extends previous work on adaptive computation \cite{artemev\_2022-06-28T16:59:28Z\_memory, he\_2020-06-05T19:54:34Z\_deberta} and state-space models \cite{gu\_2021-10-26T19:44:53Z\_combining}.

\section{Related Work}
\label{sec:related}
Recent efforts in efficient model design have sought to balance computational complexity and memory demands. State-space models have emerged as a compelling alternative to Transformer architectures for processing long-term dependencies, reducing computational complexity from quadratic to linear \cite{gu\_2021-10-26T19:44:53Z\_combining, wang\_2023-09-23T15:55:12Z\_state}. In parallel, adaptive computation techniques have been explored in reinforcement learning and language modeling, where dynamic decision-making facilitates selective processing paths \cite{huang\_2024-05-31T10:41:03Z\_decision, zheng\_2023-05-22T15:36:06Z\_response}. Additional research has focused on sparsification and reversible fine-tuning methods to mitigate resource consumption during inference \cite{liao\_2023-06-01T09:26:17Z\_make, zhang\_2024-05-07T17:44:54Z\_switchable}. Our work distinguishes itself by integrating a dynamic computation scheduler with hybrid MambaFormer models, enabling token-level branch selection that adapts processing based on input complexity. This unified framework allows for direct comparisons with static pipelines while addressing the unique challenges posed by variable input scenarios.

\section{Background}
\label{sec:background}
To appreciate our method, it is essential to understand key concepts in hybrid sequence modeling and adaptive computation. The MambaFormer architecture leverages both self-attention and linear state-space modules to capture global contextual relationships and efficiently model long-range dependencies. Conventionally, these components are arranged in a fixed sequence, where full self-attention is applied uniformly, regardless of the input's complexity. In contrast, adaptive computation introduces a mechanism to dynamically decide the appropriate processing pathway for each token. Our approach computes a token statistic—typically the mean activation of features—followed by a gate function implemented as a small feed-forward network. This function, defined as
\[
  \text{gate\_weights} = \sigma(W \times \text{mean}(x) + b),
\]
assigns a weight to each token. Tokens with gate weights exceeding a preset threshold are processed with full self-attention, while those below the threshold follow a reduced-cost branch, such as sparse attention or linear state-space computation. This selective routing minimizes redundant operations, contributing to efficient resource use in real time. The proposed methodology extends prior work on adaptive computation and memory-safe processing \cite{artemev\_2022-06-28T16:59:28Z\_memory, gu\_2021-10-26T19:44:53Z\_combining}.

\section{Method}
\label{sec:method}
Our approach enhances the baseline MambaFormer architecture by incorporating a dynamic scheduler that determines the processing pathway for each token. The architecture comprises three main computational modules: a full self-attention module, a linear state-space module, and a sparse attention module. Central to our design is the decision module, which is implemented as a compact feed-forward network. During the forward pass, each input token is first subjected to a computation of its token statistic, computed as the mean of its features. This statistic is then transformed using a linear layer followed by a sigmoid activation to obtain the gate weights. The decision rule is simple: if the gate weight for a token exceeds a set threshold, the token is processed using the full self-attention module; otherwise, it is routed to an alternative branch—either the sparse attention module or, under specific conditions, the linear state-space module. Dynamic sparsification is further applied to reduce the active number of attention operations when overall input complexity is low. Training is performed end to end using standard gradient descent methods and loss functions such as mean squared error or cross-entropy, depending on the task. This structured routing strategy, which draws inspiration from adaptive computation frameworks \cite{zhang\_2024-05-07T17:44:54Z\_switchable} and memory-safe computation techniques \cite{artemev\_2022-06-28T16:59:28Z\_memory}, provides a flexible mechanism to optimize resource allocation based on input complexity. The mathematical formulation can be summarized as follows: given an input tensor \(x\), compute \(\text{token\_stats} = \text{mean}(x)\) and \(\text{gate\_weights} = \sigma(W \times \text{token\_stats} + b)\); tokens with \(\text{gate\_weights} > \text{threshold}\) are processed by full self-attention, while the others are processed via alternative branches.

\begin{algorithm}[H]
\caption{Adaptive Token Routing}
\begin{algorithmic}[1]
  \State Compute token\_stats \(\gets\) mean\((x)\)
  \State Compute gate\_weights \(\gets\) sigmoid\(W \times \text{token\_stats} + b\)
  \For{each token in \(x\)}
    \If{gate\_weight \(>\) threshold}
      \State Process token with full self-attention.
    \Else
      \State Process token with alternative branch (sparse attention or linear state-space).
    \EndIf
  \EndFor
\end{algorithmic}
\end{algorithm}

This design is amenable to further tuning, including potential integration with reinforcement learning strategies to reduce decision overhead.

\section{Experimental Setup}
\label{sec:experimental}
We evaluated the adaptive computation scheduling mechanism through three sets of experiments.

In Experiment 1, we compared the adaptive MambaFormer model with a static hybrid baseline on standard NLP tasks, including text classification (using the IMDB dataset) and translation tasks (evaluated via BLEU scores). Both models processed identical input sequences. We measured inference time using Python\textquotesingle{}s time module, recorded memory usage with PyTorch\textquotesingle{}s memory\_allocated(), and assessed task accuracy.

Experiment 2 consisted of an ablation study to isolate the contributions of individual components. Four variants were constructed: (a) the full adaptive model, (b) an adaptive model with dynamic sparsification disabled, (c) an adaptive model using a fixed (non-learnable) gating mechanism, and (d) the static baseline. These models were trained on a synthetic dataset specifically designed to simulate varying token complexities. The training process utilized mean squared error loss in an autoencoding framework over multiple epochs, with detailed logging of average loss per epoch.

Experiment 3 focused on real-time on-device inference. Both the adaptive and static models were exported to ONNX and deployed in a simulated edge environment (such as a Raspberry Pi). A real-time data stream with variable token complexity was input to the models, and per-iteration latency, branch activation statistics, and resource utilization (CPU and memory usage, monitored via psutil) were recorded. Fixed random seeds and consistent hyperparameters (e.g., \(d\_model = 256\) and predetermined threshold values) ensured reproducibility across experiments.

\section{Conclusion}
\label{sec:conclusion}
In this paper, we presented an adaptive computation scheduling framework for hybrid MambaFormer models that dynamically allocates computational resources based on token-level input complexity. By integrating a lightweight dynamic scheduler with a gating mechanism, our model selectively routes tokens through full self-attention, linear state-space, or sparse attention branches. Through extensive experiments—including inference speed comparisons, ablation studies, and real-time on-device simulations—we demonstrated that while our adaptive model successfully implements token-level branch selection, the current decision overhead results in slower inference compared to static baselines. The ablation studies revealed that, although dynamic gating and sparsification do not hinder training convergence, their potential efficiency advantages are highly sensitive to tuning. Future work will focus on refining the gating strategy, exploring alternative thresholding techniques, and potentially leveraging reinforcement learning to mitigate overhead. These advancements aim to enhance resource utilization and contribute to the development of hardware-aware, adaptive neural networks, thereby advancing efficient deep learning methodologies \cite{gu\_2021-10-26T19:44:53Z\_combining, zheng\_2023-05-22T15:36:06Z\_response}.
